# pregnancy-smoking-analysis
Analysis of regional variation in smoking prevalence at delivery in England using R.

# Project Overview
This project analyses regional variation and quarterly trends in smoking prevalence among women at the time of delivery in England during the 2025/26 financial year. Using NHS England data, I used R and the tidyverse to clean and explore the data, calculate prevalence, and create visualisations comparing regions over time.

The aim was to identify geographical differences in smoking prevalence and consider how public health services could use these findings to inform targeted maternity smoking cessation support. The analysis is descriptive and does not establish the causes of regional differences. Findings should also be interpreted in light of data-quality limitations and the change in the data collection methodology from Q1 2025/26.
